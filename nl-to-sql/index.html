The built-in translator is rule-based: it understands counts, totals, averages, highest and lowest, grouping ("by owner"), filters ("in London", "over 10,000", "after 2026-10-01", "in October"), sorting and top N, over one table at a time. Claude mode handles freer phrasing and joins across tables. You can edit the SQL in step 3 and run it yourself. Only read-only SELECT queries are allowed.
